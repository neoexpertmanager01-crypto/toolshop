# ToolShop — глосарій (Ubiquitous Language)

Єдині терміни, якими користуються і команда, і код. Назва в коді вказана в дужках.

| Термін | Контекст | Визначення |
|--------|----------|------------|
| **Товар** (`Product`) | Каталог | Інструмент чи верстат, який магазин продає: назва, категорія, поточна ціна, залишок на складі, характеристики. |
| **Категорія** (`Category`) | Каталог | Група товарів одного типу, напр. «Фрезери», «Шуруповерти». Може мати батьківську категорію. |
| **Залишок** (`Product.stock`) | Каталог | Кількість одиниць товару, доступних для продажу зараз. |
| **Резервування** (`Product.reserve`) | Каталог | Зменшення залишку під підтверджене замовлення, щоб той самий товар не продали двічі. |
| **Замовлення** (`Order`) | Замовлення | Запит покупця на купівлю одного чи кількох товарів із доставкою. Має статус: нове → підтверджене → відправлене (або скасоване). |
| **Позиція замовлення** (`OrderItem`) | Замовлення | Рядок замовлення: товар, кількість і **ціна на момент замовлення**. |
| **Покупець** (`Order.customerId`) | Замовлення | Користувач, який оформив замовлення. |
| **Платіж** (`Payment`) | Оплата | Оплата конкретного замовлення на його суму. Статус: очікує → оплачено / відхилено. |
| **Відправлення** (`Shipment`) | Доставка | Передача оплаченого замовлення службі доставки; має адресу й номер накладної. |
| **Менеджер** (`UserRole.MANAGER`) | Користувачі | Працівник магазину, який веде каталог і обробляє замовлення. |

## Терміни з різним значенням у різних контекстах

- **«Товар»** у Каталозі — це `Product` з *поточною* ціною та залишком, який можна змінювати.
  У Замовленні товар представлений як `OrderItem` — *знімок* назви й ціни на момент оформлення.
  Тому зміна ціни в каталозі не змінює вже оформлені замовлення.
- **«Користувач»** і **«Покупець»** — у контексті Користувачі це `User` (обліковий запис із роллю),
  а в Замовленні важливий лише його ідентифікатор як покупця (`customerId`), без пароля й ролі.
- **«Статус»** — окремий для кожного контексту: статус замовлення (`OrderStatus`), платежу (`PaymentStatus`)
  і відправлення (`ShipmentStatus`). Тому в коді завжди вказуємо, чий це статус.
